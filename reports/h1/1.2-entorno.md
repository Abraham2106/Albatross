## Topología prevista para la demo

```text
celular (captura)  --enlace local autenticado-->  laptop Windows (QVAC + SQLite)
```

Supuestos explícitos, no demostrados aquí:

- Ambos equipos presentes; Wi-Fi local o hotspot de la laptop.
- Pesos descargados de antemano en la laptop.
- Un celular autorizado y una inferencia activa.
- Sin relé entre redes distintas, sin varias computadoras maestras, sin inferencia en el celular, sin APIs de nube.

## SDK 0.18.2: APIs relevantes (contratos instalados, no docs 0.19)

Comprobado en `node_modules/@qvac/sdk@0.18.2`:

| Capacidad | API instalada |
| --- | --- |
| Provider P2P | `startQVACProvider` / `stopQVACProvider`; clave vía `QVAC_HYPERSWARM_SEED`; firewall opcional por claves públicas |
| Delegación | `loadModel({ delegate: { providerPublicKey, timeout, fallbackToLocal, forceNewConnection } })` |
| Visión | constantes `VISIONPSY_NANO_460M_MULTIMODAL_Q4_K_M` (303 143 488 B) + `MMPROJ_VISIONPSY_NANO_460M_MULTIMODAL_Q8_0` (108 782 144 B); Flash exige `modelConfig.image_no_upscale: 'on'` |
| Adjunto | `history[].attachments: [{ path: string }]` (archivo en disco, no bytes en el mensaje) |
| OCR alternativo | `ocr()` + `OCR_LATIN` / `OCR_DOCTR` (no ejecutado en 1.2) |
| Expo | El SDK 0.18.2 exporta `./expo-plugin`. La app de campo es Expo SDK 57, pero el SDK todavía no se integra ahí: la inferencia sigue en la computadora. |

La documentación pública actual (sitio v0.19.x) no se usa como contrato. El DHT de Hyperswarm en delegación **no prueba** por sí solo un enlace sin internet: el bootstrap frío documentado por QVAC es 15–45 s y usa nodos DHT. Eso queda como riesgo de 1.3/7.2.

## Requisito del reto

Se consultó la página pública de [QVAC Hackathon I (DoraHacks, official rules)](https://dorahacks.io/hackathon/qvac-unleach-edge-ai-i/official-rules). El fetch automático devolvió HTTP 409; el resumen indexado exige uso significativo del SDK QVAC (completion, multimodal, P2P/delegated inference, etc.), instrucciones de ejecución y divulgación de terceros. El texto técnico completo / ISD **no está en este repositorio** y no se recuperó entero.

**No se declara elegibilidad.** Un peer personal con inferencia delegada es compatible con el lenguaje público del SDK y del hackathon, pero no sustituye cotejar las bases oficiales completas.

## Restricciones que 1.3–1.5 deben respetar

- No HTTP en LAN como «prueba de delegación QVAC».
- No `fallbackToLocal` ni mock si el criterio pide ejecución en la computadora.
- No afirmar offline hasta medirlo con ambos dispositivos y sin ruta de descubrimiento externa.
- No borrar ni reconstruir el flujo de escritorio para declarar H1.
